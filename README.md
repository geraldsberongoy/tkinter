# GUI Applications in Python using Tkinter

## Overview
This repository contains a series of exercises designed to explore GUI programming in Python using the Tkinter library. These exercises were developed as part of a first-year college activity to gain hands-on experience with creating graphical user interfaces.

## Exercises

### Exercise 1.2
A simple GUI application that demonstrates the basics of creating a window and adding a button.

**File**: `exercise_1.2.py`

**Features**:
- Create a main window with a title and specified size.
- Add a button that prints a message when clicked.

### Exercise 2 Series
These exercises build upon the basics by introducing more complex widgets and interactions.

**Files**:
- `exercise_2A.py`
- `exercise_2B.py`
- `exercise_2C.py`

### Exercise 3
An exercise focused on creating a more interactive GUI application.

**File**: `exercise_3.py`

### Exercise 4 Series
These exercises introduce drawing shapes on a canvas and handling user input to change drawing options.

**Files**:
- `exercise_4.py`
- `exercise_4.2.py`
- `exercise_4.3.py`
- `exercise_4A.py`

**Features**:
- Draw shapes (squares and circles) on a canvas.
- Change shape, fill, and color options using keyboard input.
- Handle canvas resizing and enable a "pen" mode for freehand drawing.

### Exercise 5 Series
These exercises focus on creating a text editor with various functionalities like opening, saving, and editing text files.

**Files**:
- `exercise_5.1.py`
- `exercise_5.2.py`
- `exercise_5.3.py`

**Features**:
- Open and save text files.
- Convert text to uppercase.
- Display help and "about" information.
